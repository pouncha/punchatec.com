# punchatec.com

Site vitrine de PUNCHA TEC SARL, publié avec GitHub Pages.

- `index.html` : la page du site
- `favicon.svg` : icône
- `CNAME` : nom de domaine (ne pas supprimer)

Pour modifier le site : modifier `index.html` puis enregistrer (commit) ; la mise à jour est en ligne en 1 à 2 minutes.
